概要

Pico 2 W は、マイコン RP2350A を中心に、プログラムを置くフラッシュメモリ、Wi-Fi と Bluetooth を受け持つ無線チップ、電源回路を1枚に載せた基板である。マイコン自身は無線機能を持たないので、ネットワークに出るときはマイコンが SPI で無線チップに指示を出し、無線チップが電波を送受信する。

この資料では、まず基板上の部品のつながり（図1）を示し、次にマイコンの内部（図2）を示す。どちらも、ドライバを書くときに「どの部品の、どの経路を通るのか」を確認するための地図として使う。

基板の構成

プログラムの置き場所と起動

RP2350A はプログラム用の不揮発メモリを内蔵していない。そのためプログラムは外付けの QSPI フラッシュ（4MB）に置き、マイコンはフラッシュから命令を読み出しながら実行する。この方式を XIP（Execute In Place）と呼ぶ。フラッシュの読み出しは内部 SRAM より遅いので、マイコン内部のキャッシュが読み出した内容を保持して速度の低下を抑えている。

BOOTSEL ボタンは、フラッシュのチップセレクト信号につながっている。リセット時にボタンが押されていると、マイコン内蔵の起動コードはチップセレクトが Low に引き下げられていることを検出し、フラッシュのプログラムを起動する代わりに USB の書き込みモードに入る。PC から見えるドライブに .uf2 ファイルを置くと書き込めるのは、この書き込みモードの機能である。

無線チップ

CYW43439 は Wi-Fi と Bluetooth の通信を単独で処理するチップで、マイコンとは SPI でつながる。マイコンは送りたいデータと指示を SPI で渡し、無線チップが変調や接続の管理を行ってアンテナから電波を出す。無線チップは電源投入後にマイコンからファームウェアを書き込まれて初めて動作するので、無線を使うプログラムは起動時にこの書き込みを含む初期化を行う。

無線チップには、無線と関係のない仕事もいくつか割り当てられている。基板 LED の点灯、DC/DC の省電力モードの切り替え、USB から給電されているかどうかの検出である。マイコンのピンが足りないため、無線チップの汎用ピン（WL_GPIO0〜2）をこれらに充てている。

電源

USB の VBUS（5V）は、逆流防止のダイオードを通って VSYS になる。VSYS は昇降圧型の DC/DC コンバータで 3.3V に変換され、マイコン、フラッシュ、無線チップ、ヘッダの 3V3 ピンに配られる。DC/DC が昇圧と降圧の両方をこなすので、VSYS は 1.8〜5.5V の範囲であればよく、USB の代わりに電池を VSYS ピンにつないで動かすこともできる。

VSYS の電圧は抵抗で 1/3 に分圧され、GPIO29 から ADC で測れるようになっている。電池で動かすときに残量を推定する目的で使う。

マイコン内部の構成

図2の上段は、バスに読み書きを出す側（バスマスタ）である。CPU コアは2個あり、起動時の設定で Arm Cortex-M33 と RISC-V のどちらとしても動かせる。DMA は CPU を介さずにメモリと周辺回路のあいだでデータを転送する回路で、CPU と同じくバスマスタとして振る舞う。バスファブリックは、行き先の異なるアクセスであれば複数のマスタから同時に通せる。

中段はメモリである。SRAM には変数やスタックを置く。ROM には USB 書き込みモードを含む起動コードが焼き込まれていて、書き換えられない。OTP は一度だけ書き込める領域で、暗号鍵やボード固有の設定を保持するのに使う。

下段の周辺回路は、それぞれが制御用のレジスタを持ち、CPU から見るとメモリ上の決まった番地として現れる。ドライバを書くことは、この番地への読み書きで周辺回路を操作することにあたる。各周辺回路の信号は GPIO 機能選択を通って外部ピンに出るが、1本のピンに割り当てられる周辺回路は同時に1つだけである。そのため UART と SPI のように、同じピンを候補に持つ周辺回路を同時に使うときは、ピンの割り当てを先に決めておく必要がある。

このプロジェクトで使う部分

温度を測って自宅サーバーへ送るまでに通る部品は、図1と図2で緑色に塗った部分である。順に並べると次のようになる。

  1. マイコン内蔵の温度センサが、温度に応じた電圧を出す。
  2. ADC がその電圧を整数に変換する。
  3. CPU が整数を温度に換算し、送信するメッセージを組み立てる。
  4. CPU が SPI を通じてメッセージを無線チップに渡す。
  5. 無線チップが Wi-Fi でアクセスポイントに送り、その先の自宅サーバーへ届く。

内蔵温度センサを使うかぎり、外付けの部品は要らない。ただし、内蔵温度センサが測るのはチップ自身の温度であり、CPU や無線チップの発熱の影響を受けるので、室温とは差が出る。室温を正確に測りたくなった段階で、外付けの温度センサをヘッダのピンにつなぐ構成に変えることになる。

注意事項

GPIO29 は無線と共用

GPIO29 は、無線チップとの SPI のクロック線と、VSYS を測る ADC 入力（ADC3）を兼ねている。無線チップと通信しているあいだは、このピンはクロックを出力しているので、ADC で VSYS を測ることはできない。VSYS を測るときは、無線チップとの通信が止まっていることを保証したうえでピンをアナログ入力に切り替え、測り終えたら SPI 用の設定に戻す。無線の処理と ADC の処理を別々のタスクで動かすなら、この切り替えを両者で排他にする仕組みが要る。

内蔵温度センサは ADC の別の入力につながっているので、このピンの共用とは関係しない。影響を受けるのは VSYS の測定だけである。

基板 LED は無線チップの先にある

Pico 2 W の基板 LED は、マイコンのピンではなく無線チップの WL_GPIO0 につながっている。LED を点けるにも、無線チップの初期化（ファームウェアの書き込みを含む）を済ませてから、SPI 経由で無線チップに指示を出す必要がある。マイコンの GPIO を直接操作しても LED は点かない。動作確認用に、初期化に依存せず点滅させられる表示がほしければ、ヘッダのピンに LED を外付けする。

ヘッダに出ていないピン

RP2350A（QFN-60）の GPIO は 0〜29 の 30 本あるが、40 ピンヘッダに出ているのは 26 本である。残りの GPIO23、24、25、29 は無線チップとの接続と VSYS の測定に使われているので、アプリケーションの用途には使えない。ADC 入力としてヘッダから使えるのは GPIO26〜28 の3本である。
